Oxygen

Oxygen is a custom programming language I made for Hack Club Crescent.
Oxygen is ran in a custom interpreter written in python. Sure it's slow, but its fun, and thats what matters.
The syntax is a mix between python and lua, and it can do most basic programming things, like loops, whiles, ifs, funcs, inputs, prints, variables, and so on.
