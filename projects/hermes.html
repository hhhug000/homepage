Hermes

Hermes is a file sharing program that operates entirely over SSH, You run an instance on a server, and you can access it from anywhere
Hermes can be used on any computer with SSH, and is used 100% inside a terminal.
Auth is done based off of SSH key fingerprints, so any device with the same key logs into the same account automatically, and files can be shared between accounts
